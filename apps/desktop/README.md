# clean-my-mac desktop

Tauri 2 + React 19 + Vite + TypeScript. Architecture: `docs/ARCHITECTURE.md` §7.

```bash
corepack pnpm --filter desktop dev:mock      # browser UI on :1420 with mock data, no Tauri
corepack pnpm --filter desktop tauri dev     # the real app (read-only until you confirm a clean)
corepack pnpm --filter desktop test          # vitest: selection / nested-path de-dup / grouping / Downloads tab
corepack pnpm --filter desktop screenshots   # with dev:mock running: PNGs of every screen
```

Screenshots are generated locally into `docs/screenshots/`, which is git-ignored: none are committed.

## Layout

- `src-tauri/src/tray.rs` — the menu bar item: free space as its title (one `statfs` a minute), a
  gauge icon that turns orange below `low_space_threshold_bytes`, and a menu with Open, Scan Now, the
  last scan and the top growth of the last `growth_alert_days` (history re-read every 10 min and after
  each scan/clean). Closing the window hides it; Quit is in the menu bar menu or ⌘Q.
- `src-tauri/src/commands.rs` — the §7 commands over `cmm-core` plus `reveal_trash`, `monitor_settings`
  and `agent_status` / `agent_install` / `agent_uninstall` (Settings toggle only); blocking work on
  `spawn_blocking`, history opened lazily at `data_dir/history.sqlite` (full scans only), the last
  full scan persisted to `data_dir/last-report.json` and loaded at startup, a Downloads-tab scan
  (browse-only rules) kept in memory apart from it, core errors returned as readable strings.
- `src-tauri/src/preview.rs` — Downloads previews: QuickLook thumbnails (PNG over IPC, in-memory cache) and the
  Quick Look panel, both limited to paths whose canonical location is inside `~/Downloads`.
- `src-tauri/src/storage.rs` — the Storage view's commands (`storage_cached`, `measure_storage` with
  "storage://progress", `storage_children`); the last measurement kept in `data_dir/last-storage.json`.
- `src/api.ts` — typed wrappers; `src/mock.ts` replaces them when `VITE_MOCK=1` (simulated scan
  progress, plan/execute with one blocked and one failing item, ~90 days of synthetic history,
  an invented storage breakdown from `src/mockStorage.ts`).
- `src/state.tsx` — app state (volume, report, progress, selection, the Downloads tab's own scan and
  selection, the Confirm sheet's ids) behind `useApp()`; `src/storageState.ts` keeps the Storage
  measurement outside React so it survives screen changes.
- `src/lib/` — pure logic: risk/selection rules, nested-path de-duplication, grouping, formatting; `downloads.ts`
  for the Downloads tab (kinds, opened state, sorting, filters, ranges, main-scan badges).
- `src/screens/` — Overview, Findings (+ selection bar), Downloads, Storage, History, Settings (sidebar order,
  ⌘1–⌘6), and the Confirm sheet.
- `src/components/` — window chrome, small UI primitives, hand-rolled SVG charts.

## Passive monitoring

The daily background scan is a user LaunchAgent (`~/Library/LaunchAgents/com.zak-roz.clean-my-mac.scan.plist`)
running `cmm scan --quiet --notify` at 10:00: it records the scan to history and posts a notification when
free space is below the threshold or one item grew more than `growth_alert_bytes` in `growth_alert_days`.
It never cleans. It is installed only on request — the Settings switch or:

```bash
cargo install --path crates/cmm-cli      # a stable cmm path for the job (~/.cargo/bin/cmm)
cmm agent install [--at 10:00]          # also: cmm agent status, cmm agent uninstall
```

Thresholds live in `data_dir/config.toml` (`low_space_threshold_bytes`, `growth_alert_bytes`,
`growth_alert_days`, `notifications`); Settings shows them.

## Stack

Tailwind v4 (semantic CSS variables for light/dark, no component kit), Radix Dialog + Tooltip
(focus trap, escape handling, positioning), native checkboxes/radios (`accent-color`), inline SVG
charts. Bindings in `src/bindings/` are generated by ts-rs — don't edit them.
